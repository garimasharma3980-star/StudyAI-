# StudyAI — Real Website

A ready-to-run responsive StudyAI website.

## Run it
Open `index.html` in a browser. No build step or server is required.

## Included
- Responsive landing page
- AI explanation demo
- Quiz generator demo
- Focus timer
- Login/profile demo using localStorage
- Pricing section
- Mobile navigation

## Production note
The UI is functional in the browser. For real AI responses, accounts, cloud data and payments, connect secure server-side API routes and your chosen providers.
